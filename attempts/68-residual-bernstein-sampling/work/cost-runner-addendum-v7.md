# V7 runner details before measurements

Direct controls construct only their TWO needed RNG streams; the generic
factories construct three. No unused level RNG is imposed on the cheaper
operation. Each child has a30s API alarm, returning any available partial
outputs; the parent has a35s supervisor guard including process startup.
If that guard kills a child, preserve available stdout/stderr and explicitly
record unavailable outputs rather than fabricate them. Full child CPU/wall
are recorded in addition to API clocks. A source-tape observer and output/
diagnostic allocations are timed identically for the core methods; the source
tape uses one byte per simulated coin. These are resident-library numerical
costs including instrumentation, not deployed biological wall-clock results.
No changes to the1140 cases, algorithms,20% gate or negative stopping rule.
