1. **Real consumer.** Frozen dLLM head, original binary64 nonnegative weights,
   original token bytes/aliases, fixed canvas, JSON EOT PAD* and an unambiguous
   deterministic layered accepting graph. Return a joint original-ID word of
   the EXACT conditioned product law. Mosaic LLaDA2's published `commit_by=model`
   consumes a joint proposal and uses model confidence, WITHOUT requiring
   conditional marginals. Its source is pinned36945e4b3c64. This is an adapter
   contract for that operation, NOT reproduction of the full serving engine,
   its tokenizer semantics, ideal exponential logits or finite native RNG law.
   Exact conditional-marginal ranking is a separate operation and not supplied.
2. **Significance/difference.** Existing exact/interval recursive sampling,
   OS*2012, finite categorical sampling and EBUS2025 are nearest antecedents.
   The candidate artifact audits the ACTUALLY EXECUTED GPU proposal: explicit
   integer CDF tickets with known finite-bit density, an independently directed
   max-ratio graph pass, and one exact scalar acceptance on the sampled word.
   Approximate backward log/exp are untrusted accelerators. A full rational
   backward pass is avoided, but this is NOT a lower bound on all exact samplers;
   a classical lazy interval sampler may do as well. Mere correctness of this
   classical composition is insufficient for a paper. The own contribution
   must be a useful, substantially faster numerical implementation/contract.
3. **Why choose it.** Potentially retain GPU throughput while restoring an exact
   law for reproducible/unbiased grammar-conditioned Monte Carlo. Bound expected
   proposals by M/L, independently of tiny unconditional valid mass, on admitted
   queries. This feature is useful only if its full cost beats competent exact
   controls and the ordinary FP64 error/guarantee tradeoff is worth paying.
   Controls: exact rational CPU stack/compact CFG, certified lazy interval
   recursive GPU/CPU inference, exact integer categorical methods including
   EBUS, exact rejection/envelopes, strongest classical sparse/layered GPU FP32
   and FP64 (approximate law, explicitly retained as practical alternatives).
4. **Written proof/cost.** See work/theory-v1.md. For a fixed frozen proposal Q,
   compute a directed bound M >= max W/Q on the deterministic graph. Recover
   Q(x) EXACTLY from recorded integer CDF endpoints, including multiply-high
   range bias. Accept with W(x)/(M Q(x)). Standard rejection gives P and the
   directed lower mass L gives acceptance >=L/M. All graph arithmetic can use
   fixed precision; exact original-weight arithmetic is confined to one O(n)
   word per trial. That resource separation is comparative to full rational
   preparation, not a new rejection theorem or general optimality claim.
5. **Honest validation.** First exhaustive rational original-word laws, finite
   ticket preimage counts, fixed tokens/aliases/EOT/PAD and zero/malformed inputs.
   Then independent checks of every directed GPU primitive against Fraction,

6. **Complete dLLM cost.** Compilation/minimization/reuse, new heads, input transfer,
   class/block reductions, proposal CDFs, audit passes, RNG, all rejections,
   exact scalar bits, output back to CUDA, confidence and commitment, fixed-ID

7. **Strongest objections.** FP64 is already adequate for many users; exactness
   may have no valuable consumer consequence. Certified interval/rejection is
   old and may directly subsume this implementation. Audit/copy/launch costs
   may erase any GPU advantage. A fixed-width graph cannot model every CFG
   cheaply. Finite PRNG quality and compiler/hardware basic-instruction semantics
   remain trust assumptions. Poor proposal support/ratios can force refusal;
   no clamping or deleting positive original words is permitted.
8. **Article obligations.** Prior-art distinction beyond classical composition,
