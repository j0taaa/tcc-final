## Exact native boundary, pinned implementation only

The original `torch.no_grad` generator wrapper keeps the native iterator
in its local `gen`; inspect that frame READ-ONLY. The first neural step has
`i=0`, one block, eight transfer attempts. At a fast yield, if
`_regular_cover_committed == _n_transfer_this_step`, the step's transfer
budget is exhausted. At a fallback yield, `j` is the last index of
`range(_n_transfer_this_step-_regular_cover_committed)`. Either is the last
yield before the next model call. A true terminal yield also stops. Native
failure yields immediately return: advance to StopIteration without a
model call, retaining that failure. Unexpected frames/statuses are refused.

Do not rewrite any frame local, replay a selected prefix, alter vendor
yield/commit/EOS policy, or silently call another forward. Pin and hash both
native code and adapter. Runtime zero-new-forward audit is mandatory.

Fixed key: `(relative_position, ORIGINAL_token_ID)` of the leftmost
non-MASK/non-EOS/non-PAD body token in the boundary snapshot, excluding the
entire supplied input prefix; `NO_BODY` if absent. This is one preregistered
observation, without changing key after model outputs. Do not report its
raw frequency as an unbiased probability estimate from the adaptively
requested v4 seed bank. First-step classifications do not prove semantic
correctness. Any later full-cost evaluation needs its own frozen protocol.
