## Eight criteria, reassessed

1. Operation: a real iterative grammar-conditioned dLLM returns a numeric JSON
   PREFIX through true EOT, preserving every original ID ever committed. It
   integrates unused suffixes and never spends releases after its proposed EOT.
   The eventual consumer is a learned release policy, not validity alone.
2. Difference: V7's length-dependent anchor eligibility/normalizer and exact
   visible-action score. Classical weighted inference implements the same
   operation. Whether there is enough own originality and a useful training
   effect remains OPEN; a stopped sampler alone cannot close that gap.
3. Choice: possible lower-noise gradients without another neural reward pass.
   Cheap anchor/length/class/combined controls remain mandatory for any later
   variance gate. The present screen checks functionality and learning signal
   only; it does not compare cost-times-variance or optimize parameters.
4. Proof: V7/V7-head-chain supply the law/progress/scores. The separately
   written V8 root-budget identity calibrates one fixed input feature. All
   use classical forcing/elimination/semiring/calibration. Floating GPU code
   is an approximation, not an exact native finite-RNG certificate.
5. Experiment: ALL8 known-development V4 inputs/initial heads, two trajectories
   each, one initialization, max497 new pretrained forwards including warmup.
   Preserve all statuses and data. Numerical/resource checks and a small
   semantic-signal condition below are fixed before new outputs. No tuning
   or changed gate rescues V5; known golds are explicitly acknowledged.
6. Cost: record all compiler, calibration trials, full original head/softmax,
   class derivatives, proposals, fixed-ID handling, all score/reference paths,
   next-head work, transfers, memory and output. Diagnostic elapsed times
   cannot be promoted to competitive latency. Later methods share legitimate
   caches/preparation and pay all initialization/gradient/model work.
7. Objections: leftmost/fixed/position-only anchors, confidence/PL/native
   decoding and supervised fine-tuning may be better. The model may still
   have no useful signal. The old PAD law is NOT a competent baseline for a
   stopped-law advantage. One-shot proper stopped sampling is reported only
   as a paired functional baseline, with no quality-win inference.
8. Gap: own sufficient distinction, real full-cost variance, useful updates,
   strong behavioral controls and independent confirmation. This screen
   cannot fulfill the scientific user goal even if it passes all checks.
