# Actual prior-art scope before A43's first oracle

2026-10-11. This is not an exhaustive priority certificate.

* Mark Huber, *Optimal linear Bernoulli factories for small mean problems*,
  arXiv:1507.00843v2, 2016-09-27, DOI10.1007/s11009-016-9518-3,
  <https://arxiv.org/pdf/1507.00843>. Actually read section3.1, Fact7,
  its explicit gambler's-ruin algorithm and Lemmas4/5; section4 lower-bound
  discussion. The ruin factory and its rational absorption law are ALREADY
  known. Section4 explicitly distinguishes fixed-n Cramer-Rao from a random
  number of flips. A43 may not call either the walk or the generic factory
  a discovery. The scoped candidate is a two-ORIGINAL-output retained
  coupling, exact uniform expected cost and attaining a sharp repeat/cost
  frontier proved without unstated differentiation. This could still be a
  short direct specialization of the existing literature.
* Wolfowitz1947, *The Efficiency of Sequential Estimates and Wald's Equation
  for Sequential Processes*, Ann. Math. Statist.18:215--230, and subsequent
  efficient sequential-estimation literature are serious predecessors.
  Generic stopped-information bounds are not new. Full original text not
  yet obtained; the attempted Project Euclid address did not resolve. Do not
  treat search excerpts as having read that theorem's hypotheses.
* Gordon Simons1979/1980, *Sequential estimators and the Cramer-Rao lower
  bound*, institutional original report at
  <https://repository.lib.ncsu.edu/items/9948d12a-be8d-4e94-82f1-2180d5ff475e>,
  published DOI10.1016/0378-3758(80)90034-8. Publisher abstract and repository
  metadata read: some sequential unbiased normal-mean estimators violate the
  usual bound. Full report still needs reading. This reinforces the need for
  A43's explicit bounded three-output KL argument; it does not refute or
  establish that argument by itself.
* Akahira/Koike1998, *On the properties of statistical sequential decision
  procedures*, Sugaku Expositions11(2):197--213, institutional record at
  <https://tsukuba.repo.nii.ac.jp/records/28306>. Metadata only obtained so
  far; full text not read. Its completeness, stopping-rule and efficiency
  sections are necessary to inspect before any priority claim.
* Known-class-mass Fréchet antithetics and ranked-set sampling already avoid
  generic variance inflation. A42/A41 primary audits preserve these stronger
  objections; no mutable code is reused. Free exact masses/inverses can make
  A43 unnecessary. A binary unknown-mass bound is not a dominance theorem
  over a full source-space sampler supplied with known addresses.

Neither a failed keyword search nor absence in the sections actually read
proves novelty. No large model campaign or article promotion is justified
before checking the sequential-estimation objection and useful full costs.
