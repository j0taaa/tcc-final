## Eight scientific decision questions

1. **Use.** Two expensive original dLLM noising loss/gradient evaluations of
   a fixed CFG-valid JSON/DSL target, preceded by cheap corruption draws and
   a fixed binary structural/learned proxy. Keep the paid first corruption.
   A native decoder continuation is admissible only with a genuinely cheap
   informative boundary; A42 V11 shows the root operator is NOT such a boundary.
2. **Difference.** Investigate an UNKNOWN-class-mass coupling with a sharp
   EXPECTED-query frontier, rather than another fixed-pool matching law.
   A first random-walk excursion may give exactly M expected raw sources for
   every class mass, with repeat probability1/M at balanced masses. Classical
   gambler's ruin, path reversal, Bernoulli factories and sequential information
   bounds are antecedents. The coupling/frontier may already be known.
3. **Choice.** Same individual original marginals, two expensive evaluations,
   arbitrary-vector covariance never above iid2 despite an inaccurate proxy;
   at balanced masses class-mean variance factor2/M versus iid2. Compare to
   competent binary fixed-pool frontier, retained RSS, known-mass/inverse,
   pivotal, count/time stratification, CV and extra iid evaluations. The bound
   is not against free exact class masses or a score-aware estimator. It has
   an unbounded query tail; latency/memory/resource refusals must be charged.
4. **Without code.** Start a signed IID label walk with the first source;
   stop at its first return to0 or first hit of +/-M; return first and last
   ORIGINAL sources. Prove path-reversal invariance, original marginals,
   covariance, E[N]=M, and balanced optimality E[N]*P(repeat)>=1 for every
   universally correct adaptive unknown-mass coupling. Use data-processing
   KL and local finite-output algebra, not an unjustified stopped Cramer-Rao
   differentiation. A successful code example cannot close this proof.
5. **Experiments.** Initially independent exact absorbing-chain calculations,
   raw-source alias and residual checks, arbitrary-vector covariance and cost.
   These are correctness/proof aids, not model wins. Only after proof/prior
   audit, freeze an application protocol with all input-eligible external cases
   and complete-cost competent controls. No favorable corpus selection.
6. **Costs.** M expected original-source preparations/classifications, two
   expensive evaluations, fitting/grammar analysis, O(1) source storage and
   O(log M) walk state. Query tail is unbounded; a path-dependent timeout
   followed by ordinary iid fallback DOES NOT inherit marginal correctness.
   No production deadline behavior or exact conditional-after-refusal claim.
7. **Objection.** The rule may be an existing Bernoulli factory or sequential
   sampling design. Binary proxy variance can be weak; mass-aware inverses
   may win. A random number of expensive helper forwards would erase the
   benefit. Whole-gradient/training/generation guarantees must not be inferred
   from an arbitrary-vector one-estimator bound. A known technique plus JSON
   is not a scientific advance.
8. **Publication.** Need a distinctive frontier actually checked against
   primary literature, a correct complete proof, a meaningful CFG/dLLM use
   and useful full costs. No priority, human review, acceptance, full-model
   training or EPIC superiority is asserted. Main article/API stays unchanged.
