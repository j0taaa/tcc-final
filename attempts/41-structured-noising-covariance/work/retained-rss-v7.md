# A classical ranked-set control CAN retain the paid original anchor

2026-10-11, AFTER the v6 information observations and BEFORE a competitive
protocol. No new neural calls. This is an adversarial reduction of a claimed
application distinction, not a new contribution or a favourable benchmark.

Fix a cheap total preorder on ORIGINAL source states before the expensive
first score. Let q be the original source law. The standard oriented RSS2
joint law is (q_min tensor q_max + q_max tensor q_min)/2, from independent
two-source min/max pools with fair ties. Its first marginal is q, since
q_min+q_max=2q. Its covariance is -d d^T, d=E_min G-E_q G, for EVERY score G.
This arbitrary-imperfect-order covariance guarantee is already classical.

Given a paid literal anchor X, sample independent cheap pilot B. If B>X,
assign X the min role; if B<X, the max role; on a tie use a fair coin.
Draw two more independent cheap states C,D. If X has the min role, return
max(C,D); otherwise return min(C,D), using fair ties. This needs four cheap
original states including X but only ONE new expensive evaluation. It does
not need class masses, CDF values, inverse strata or the actual anchor score.

Proof: conditional on X=x the min-role probability is
P(B>x)+P(B=x)/2=q_min(x)/(2q(x)); similarly for the max role. Multiplying
by q(x) gives exactly the oriented RSS2 joint law. Original second marginal
is preserved, the first is literal, and no source-score observation is used
to choose the preorder. This conditional simulation is a direct consequence
of the known RSS law, not a claim of a new sampling technique.

Therefore it is INCORRECT to justify A41 over RSS by saying the latter must
discard/recompute the paid first neural score. Four versus adaptive cheap
queries, and the actual proxy geometry, are the remaining differences.
Similarly lazy pivotal has the SAME C4 law/shortcuts. Current score/gradient
variations and all fitting/source/NN costs must decide any practical choice.
