## Eight criteria: same theorem, more meaningful neural application

1. Return an unrestricted numerical JSON answer to an actual externally
   authored request. Two candidates and an external verifier are useful for
   quantitative decision systems; no gold answer catalog enters grammar.
2. Classical factories/reflecting walks remain credited. Candidate novelty
   is the sharp disagreement/minimax-work contract and native whole-trajectory
   integration; it STILL needs primary priority review. Dataset is no novelty.
3. Need higher semantic coverage per full cost over native EPIC and competent
   raw-noise/density-aware coupling and mixed-temperature alternatives. A
   theoretical nondecrease alone or finite dual certificate is insufficient.
4. Written A32 proofs apply to arbitrary native row P and pre-noise class,
   preserving the first path and both original trajectory laws. Known-p
   alternatives are deliberately outside the p-blind optimum, not weakened.
5. Freeze task, seeds, methods and gates BEFORE heads. All32 development
   inputs and later all64 independent inputs, every status/loss. An initial
   one-seed pilot is diagnostic; never call it independent confirmation.
6. Include one-time grammar/prelex/class setup, prompt preparation, row
   coordination, actual new model forwards, cache/transfers, complete native
   recovery, verifier and output. Separate first-use/amortized costs, noise
   oracle operations and whole latency. Give baseline the SAME caching and
   prelex reuse; original EPIC optimizations remain enabled.
7. Compact/vectorized empirical pools have the SAME theoretical pair law;
   do not demand better expected quality against the same law. A known-p
   class rejection/CDF control may be cheaper/better but must disclose finite
   native-law approximation and refusal budgets. Zero gain, higher forward
   work or density-aware dominance can reject this application.
8. Need genuine independently confirmed magnitude and checked own claim.
   No human review/publication/EPIC general-speed victory is presumed. If
   this input family fails, retain it and do not relax/select cases afterward.
