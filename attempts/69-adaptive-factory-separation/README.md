# A69 — Adaptive exact simulation beyond finite-mean preselected batches

2026-10-17. Written BEFORE code, models or timings. A68's numerical application
remains CLOSED negative; this is a different capability question.

1. **Operation/use.** Exact simulation of a response f(p) from a sampling-only
   probability p is an existing computational-statistics operation, including
   Bernoulli-factory libraries. Compare an adaptive sequential reader with
   the interface which preselects and consumes its entire sample size before
   inspecting outcomes. The latter also supplies the ancestry-before-colours
   interface of the published population-genetics consumer. The candidate is
   a resource-capability theorem, NOT a replacement genealogy construction.
   The separating response is a constructed mathematical object; a natural
   external application needing this distinction is STILL MISSING. No native
   dLLM/GLC benefit, deployment or fulfilled original user goal is asserted.
2. **Own difference.** Candidate: an explicit bounded response has an exact
   adaptive factory with uniformly finite expected input calls and finite
   expected full bit work at EVERY parameter, while EVERY fully preselected
   factory for the SAME response has infinite expected input size. General
   mixtures, early stopping, sequential tests, Hoeffding bounds and score
   differentiation are classical. Specific priority of this separation and
   its sufficient significance are OPEN; keyword search is not a certificate.
3. **Why choose it.** The candidate difference is finite versus infinite
   expected work, not a small timing against an inefficient implementation.
   The lower bound admits ALL preselected sample-size laws and ALL randomized
   output kernels, with arbitrary computation/knowledge of f. It does NOT
   constrain other adaptive factories, informed-p methods or methods which
   inspect pilot input calls before selecting a budget. Real practical value
   still requires more than an engineered proof object.
4. **Proof first.** work/theory-v1.md gives the algorithm, law, uniform input-
   cost bound, pointwise bit cost and a non-C2 separation at an interior
   accumulation point. The nonadaptive obstruction uses a classical Bernstein
   derivative bound. Local C1,1 regularity uses the classical stopped-score
   argument; it is not called a new differentiation principle. These are
   WRITTEN proofs awaiting independent checking, not Lean or human review.
5. **Validation.** At most a small exact correctness/counterexample audit
   after proof freeze: finite prefix predicates, separate enumerated word
   laws, stopping work, Bernstein derivative inequalities and malformed
   inputs. Constructed cases are proof objects, not a practical benchmark.
   NO competitive campaign, neural capture or natural-application claim.
6. **Full cost.** Count all source calls, level/gate random bits, counters,
   rational dyadic comparisons and output. Expected input size is uniformly
   finite; expected BIT work is only proved pointwise finite, not uniformly
   bounded in p. Huge rare finite branches are explicit. Unknown-p source
   calls have their supplied physical cost; no artificial delay is added.
7. **Fatal objections.** A known adaptive/nonadaptive regularity separation
   could subsume this result. The C1,1 construction may be too artificial to
   satisfy the user's use requirement. The lower bound is limited to a
   genuinely preselected, fully consumed input batch, not all exact samplers.
   Any flaw in nesting/cost/off-centre bounds defeats the claim. The old
   negative numerical gate is not reopened by this different theorem.
8. **Article gap.** Audit the written separation and original closest sources;
   confirm specific novelty and a useful own consequence beyond this proof
   object. If these remain absent, do not build an extensive implementation
   or promote it to an article. The positive goal remains OPEN.
