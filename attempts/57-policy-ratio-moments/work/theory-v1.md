# V1 — Three positive queries for conditional importance moments

Written2026-10-16 BEFORE code or new numerical readouts. This is a computational
specialization of ordinary importance sampling/evidence and conditional
expectation. No new general RB theorem, parsing method or priority is claimed.

## Contract

At a sufficient visible state s, fix original token IDs F and an explicit
active set. There are at most n slots. A completion x contains original IDs
through its FIRST EOS, at exclusive length T. Its bytes before EOS obey the
unambiguous declared grammar, every fixed ID matches and T>max(F). Unused
suffixes integrate to1, not model PAD factors. Let I(T) be active slots i<T.
On nonterminal feasible states it is nonempty. The COMMON proposal is

    P(x|s)=W(x)/Z,  W(x)=product_(i in I(T)) c_i(x_i),

where c are finite nonnegative original-ID weights and Z>0. Zero branches
are omitted, never divided by. Fixed singleton rows have weight1. A bounded
unambiguous weighted grammar circuit implements a positive prefix sum; this
is an assumption about an available representation, not a new compiler.

Planner k=0,1 has gates0<g_ki(v)<1 and weights u_ki>0. Draw x~P, then anchor
j in I(T) with probability u_kj/H_k(T), where H_k(T)=sum_I(T)u_ki. Force j
retained, retain other active i<T independently with probability g_ki(x_i),
and expose only a=(B,t_B), B nonempty. Hidden x,j,T never affect the next
state except through a. Every newly fixed ID stays in the output prefix.

For a compatible x, put h_ki(v)=g_ki(v) if i in B and1-g_ki(v) otherwise;
retain the original-ID filters at B and F and the minimum EOS extent. Define

    q_k(x)=W(x)*product_(i in I(T)) h_ki(x_i),
    r_kj=u_kj/g_kj(t_j), j in B,    S_k=sum_B r_kj,
    Q_k=sum_(compatible x) q_k(x)/H_k(T).

Then the joint law and observed mass are

    L_k(x,j,a)=q_k(x)*r_kj/[Z*H_k(T)],
    K_k(a|s)=S_k*Q_k/Z.

Proof: the forced anchor omits exactly its retained Bernoulli gate. Factor
the product containing all retained gates, compensate by1/g_kj, then sum j.
The law is normalized because it was generated by the declared three-stage
experiment. In particular x and j are independent GIVEN a under behavior0:
their posterior factors are q_0(x)/(H_0(T)Q_0) and r_0j/S_0.

## Exact means and second moments

Strict gate/anchor positivity and a COMMON proposal give the same compatible
support for the two policies. For an observed positive-mass a, set

    w_F(x,j)=L_1/L_0=(q_1/q_0)*(r_1j/r_0j)*(H_0/H_1),
    w_X(x)=E_0[w_F|a,x]=(q_1/q_0)*(S_1/S_0)*(H_0/H_1),
    w_V(a)=K_1/K_0=(S_1/S_0)*(Q_1/Q_0).

The three positive partition queries needed for all these moments are Q_0,
Q_1 and

    Q_20=sum_x [q_1(x)^2/q_0(x)] * H_0(T)/H_1(T)^2.

The third is an ORDINARY unary-weighted grammar query: its active row has
weights c_i(v)*h_1i(v)^2/h_0i(v), original filters unchanged, and its EOS
edge has terminal factor H_0(T)/H_1(T)^2. No gate or anchor factor is applied
after the first EOS. This is classical reweighting, not a special semiring.
If W=0 that branch contributes0; never evaluate0/0. Let R_20=sum_B r_1j^2/r_0j.
Directly summing the factored behavior posterior gives

    E_0[w_F|a]=E_0[w_X|a]=w_V,
    E_0[w_F^2|a]=(Q_20/Q_0)*(R_20/S_0),
    E_0[w_X^2|a]=(Q_20/Q_0)*(S_1/S_0)^2.

Subtract w_V^2 for conditional variances. The factor R_20/S_0 is at least
(S_1/S_0)^2 by Cauchy--Schwarz; both second moments are at least w_V^2.
These are EXACT ARITHMETIC identities, not a floating-point error bound.

## Competent ID-class and length controls

Assume each original-ID prefix has one deterministic class path gamma,
including length, and membership/acceptance depends only on that path. A
fixed global class map that preserves every lexical-state transition suffices;
identical-byte aliases also suffice. Retained and fixed IDs remain literal.
Write A_ki(C)=sum_(v in C) c_i(v)h_ki(v) on unretained active rows; retained
rows have the literal single-ID factor. Product A_ki is q_k^C(gamma).

Integrating unretained original IDs conditional on gamma and anchor gives

    w_CA=(q_1^C/q_0^C)*(r_1j/r_0j)*(H_0/H_1),
    w_C =(q_1^C/q_0^C)*(S_1/S_0)*(H_0/H_1).

Their conditional second moments use Q_20^C with class row A_1i(C)^2/A_0i(C)
and the same terminal factor. It is INCORRECT to sum c*h_1^2/h_0 within a
class and call that the class-integrated second moment: that keeps ID noise.
Zero class mass contributes0 under this common support. Class summaries cost
O(nV); no extra neural query is required. This control can erase the claimed
benefit and must not be replaced with a needlessly weak full-latent control.

For length control, let Q_kt=sum_(x:T=t) q_k(x)/H_k(t), obtainable by ordinary
inside propagation to each accepting EOS edge. The conditional ratio retaining
only T is w_T=(S_1/S_0)*Q_1T/Q_0T. Consequently

    E_0[w_T^2|a]=(S_1/S_0)^2 * sum_t Q_1t^2/Q_0t / Q_0.

The required two inside runs also supply Q_0,Q_1, so the fully visible ratio
has essentially the SAME preparation. No speed advantage over that ordinary
evidence implementation is claimed. Class and length sigma fields are not
arbitrarily ordered; compare their actual moment rather than assert an order.

## Adaptive path and reward corollary

Use a common finite horizon and absorbing terminal states. s_t includes ALL
control state needed by the future kernel; an old visible path O determines
every s_t and a_t. Independent fresh latent draws at each step imply

    W_V(O)=product_t w_V,t,
    E_0[W_F^2|O]=product_t E_0[w_F,t^2|a_t,s_t].

Proof: the joint density along the fixed visible path factors into the visible
path mass times the independent local auxiliary posteriors. Summing the
product gives the product of local moments. This remains true when parameters
and the common head depend on s_t. Reusing only canvas when hidden budgets/
EOS/agenda affect the future invalidates this argument.

Let R be measurable from O, or use fresh reward randomness conditionally
independent of the discarded auxiliaries given O. For an O-measurable common
baseline b, conditional auxiliary variance of (R-b)W_F is (R-b)^2 times
E[W_F^2|O]-W_V^2 (or its conditional expected reward-square counterpart).
Marginal IS is unbiased for target visible returns under absolute continuity.
The relative hidden second moment equals1+the chi-square divergence between
the target and behavior auxiliary POSTERIORS along O. Products can amplify
it, a classical likelihood-ratio fact.

This does NOT compute the variance over visible paths, global ESS, target
quality or useful sample savings. In particular arbitrarily poor visible
overlap can persist after perfect collapse. Observed NFE count may be a
visible reward; hidden proposal/runtime cost generally is not. Clipping/WIS
changes the estimator and may improve actual MSE despite bias. DR and SFT
remain competent different-operation/practical controls when applicable.

## Support and cost boundaries

Changing a hard deterministic action map may put target joint mass on old
zero-preimage branches, EVEN WHEN observed action laws have common support.
Then a full-latent ratio formed only on behavior support can have the wrong
mean. The smooth common-proposal contract avoids that failure; it is NOT a
theorem about arbitrary native sampled-confidence/greedy decoder updates.
Changing the proposal requires its own density/normalizer ratios and support
audit; omitted here. No final-TEXT likelihood is computed by path products.

If one grammar sum costs C arithmetic operations and M memory, visible ratios
need2C, full second moments3C, class control one additional reweighted query
after class preparation. H/S/R sums are O(n), dense gates/class preparation
O(nV). The same grammar circuit is reused; all graph preparation is counted.
For rational inputs bit lengths can grow with the horizon; operation counts
are not bit-cost bounds. Full common-head cost and retained-path IO do not
disappear when Z cancels algebraically. No competitive timing is supplied.
