# V4: test the real accepted-event boundary before a large campaign

2026-10-11, BEFORE native code/heads. Refines the eight README criteria;
the frozen v1--v3 proofs/evidence remain independent. No posterior replacing
EPIC, no change to upstream, no artificial semantic success benchmark.

1. **Use.** Two arithmetic-program JSON candidates generated from a word
   problem, consumed by a real interpreter/later selection. Internal nodes
   have op add/sub/mul/div and two recursive args; leaves are unrestricted
   JSON numbers. This is generation of an executable explanation, not the
   rejected Boolean-rule/model-training proposals15/16. Grammar sees no gold
   answer. Two-output/unknown-verifier contract must be justified explicitly.
2. **Difference.** A34's restricted-pair sharp oracle frontier is the candidate
   result; generator suspension, cached logits, classic ruin/stratification and
   arithmetic reasoning are NOT claimed new. The prototype only locates a
   faithful operation that can benefit from the theorem. No priority assertion.
3. **Choose.** Need cheap original-law native draws BEFORE two costly future
   continuations and a class with semantic signal. Without both, reject this
   application. Original EPIC iid2, more-output iid, raw-noise stratification,
   mixed/deterministic and probability-aware alternatives remain controls.
4. **Mathematics.** Each iid oracle payload includes a suspended UNMODIFIED
   native generator, its actual first yield, all rejected choices/control
   locals and complete RNG tapes. It includes nonprogress/refusal outcomes,
   not only successful commits. Classification and stopping use that yield;
   retain first/last original payloads and independently resume their own
   tapes. Payload theorem therefore applies to the specified finite RNG law
   even when ideal PL fails. No decoder probabilities are substituted.
5. **Prototype checks.** First use FAKE heads with the literal pinned native
   generator on CPU/CUDA. Interleave/discard auxiliary generators, then compare
   the entire first trajectory, EOS, original aliases, rejected choices and
   RNG streams to a baseline. This is correction, not neural benefit. Only
   after passing may a SMALL preregistered input-only diagnostic measure first
   native-event variability/cost. No favorable case is a confirmed victory.
6. **Full costs.** The model is in eval mode and frozen. Shared initial head
   must be identical; clones, RNG capture/restoration, parser, retries, class
   evaluation and suspended state all count. A subsequent forward during an
   auxiliary draw is counted, never called free. A complete-cost campaign
   needs equally optimized caches and preparation on every comparator.
7. **Objections.** First native yields may contain only punctuation or no
   progress; classes can be degenerate/no semantic signal. Finite seeds/RNG
   states are payloads, not ideal independent Gumbels. More full candidates
   and verified retry can win. Correct suspension alone is not utility.
8. **Article.** Need a nontrivial accepted semantic partition, actual same-cost
   benefit and specific-priority comparison. Native prototype and diagnostic
   cannot fulfill that. Keep code minimal and isolated, no baseline edits or
   campaign expansion before the cheap-boundary diagnostic succeeds.

Contract for the first prototype: first EVENT of the native generator,
including failure/nonprogress, not an event-only-success rejection sampler.
The mathematical oracle returns whole payloads. Full histories/local control
remain in the suspended generator; no mutable canvas-only reconstruction.
No external data or new head is consumed by the FAKE probe.
