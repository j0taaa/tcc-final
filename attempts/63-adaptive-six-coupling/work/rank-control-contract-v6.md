## Construction and law, without any probabilities

Number six virtual positions0..5. Choose an anchor R uniformly, independently
of the source. Put the literal first payload at position R. Query other
positions in either of TWO predeclared orders:

1. remaining positions in ascending numeric order;
2. cyclic order R+1,...,5,0,...,R-1.

Both orders are fixed before seeing keys; retain both results. Sorting the
complete position tape by (key, original position) gives six ranks. Pair each
rank r with r+3 modulo6. This is an ordinary empirical half-rotation matching,
not an invention of A63. With three key blocks it minimizes repeats and has
the same ordered key-pair law as uniform minimum-repeat matching after the
uniform anchor and iid tape average: all atom diagonals are optimal, the
joint matrix is symmetric, and three-key symmetry+marginals+diagonals uniquely
determine the matrix. Ties retain all original position multiplicities.

Why the anchor matters: after assigning independent source draws to the chosen
position order, the FULL position tape has law P^6 and is independent of R.
Conditional on that tape, R is uniform. Any fixed-point-free matching is a
permutation, so both chosen positions are uniform. Always taking the lowest
rank/first position instead would not have this argument.

At an observed prefix enumerate ALL compatible assignments to unqueried key
positions, without P. If every completion gives the same partner KEY and that
key has a nonfirst observed representative, stop. Return that earliest nonfirst
original payload. Otherwise query the next position. At six all assignments
agree. Key-only nonfirst replacement preserves the conditional raw P|key law
and its independence from the first payload. It need not preserve the literal
partner index/RNG tape of the full rank algorithm. All original FAIL/status
payloads remain included in the fixed key map.

This is a complete conservative lazy evaluation of a known rank construction.
It sees the same opaque source as the candidate, with no free probabilities or
new neural forward. Its table preparation must be charged before runtime claims.
Other adaptive query orders or classical factories might be better still.
