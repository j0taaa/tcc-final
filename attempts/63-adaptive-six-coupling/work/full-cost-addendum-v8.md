before any model campaign. The original algebra under its explicitly additive

Candidate-specific nonnegative coordination/preparation makes its own comparison
more demanding. A common one-time model load can be amortized separately in a
repeated-estimation workload. However, if genuine unavoidable work C is paid
for EACH pair by both methods, their costs become

    A*c+2v+C and2c+2v+C,

and Equation1 instead has denominator A+2r+C/c. Thus the r>2027/1053 necessary
condition applies ONLY when C=0 (or in the specified amortized cost model),
not to arbitrary full workloads. Real shared per-pair work can relax that
particular threshold. It cannot be invented to favor a sampler.

Similarly the oracle regression comparison in V8 is an exact statement under
the displayed normalized cost model. Different actual coordination/setup or
shared per-pair work needs to be included again before a real efficiency claim.
Its algebra does not establish that a fitted practical CV always wins.

No measured source/evaluation ratio, application failure, new model score,
training result or full-cost victory follows from either note. The next real
consumer protocol must specify precisely which shared costs are per pair and
which are one-time; the positive source-work theorem stays independent.
