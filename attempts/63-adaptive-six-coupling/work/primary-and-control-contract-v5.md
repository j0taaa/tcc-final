## Complete count-polynomial/CDF adaptation to THIS pair law

Given first class i, the full-six matching law provides a known conditional
coefficient q(j|i,n) for every possible total multiset n of size6. Compute it
by all15 perfect matchings on a representative first-i tape and retain every
minimum-repeat matching. A Goyal/Sigman-style construction draws the remaining
five iid keys and selects j by one independent U and the fixed label order
0,1,2. Conditional on the key multiset, this is exactly the matching partner
law. Return an observed nonfirst original payload with class j. Any class
with positive q has a nonfirst representative; this must be checked.

A competent classical control need not always draw all five remaining keys.
At each prefix, enumerate ALL key-count completions consistent with it.
For each j, intersect its CDF interval across completions. If the SAME U
belongs to that intersection, output j immediately; otherwise request another
original input. This is ordinary exact short circuiting, not a new algorithm
claimed here. No estimation/truncation of P, dropped failure or support change.

Before execution freeze a small independent control/auditor. Enumerate ALL729
named six-tapes and the complete rational partition of U induced by EVERY
conditional full-pool CDF endpoint. The midpoint of each open cell has the
same behavior throughout that cell; zero-probability endpoints use half-open
intervals. Refuse after1000000 transcript nodes. Check the operational key
law against the full matching on EACH tape, raw nonfirst availability, and
universal marginals/diagonals by all multiset coefficients. Report U3 expected
calls and each of the original five weighted laws, including any tie/loss.
This is a mathematical complete control, not published-package execution,
timing or a hand-tuned neural baseline. Charge table construction/lookup
separately before any future full-cost comparison. Fixed-order asymmetry may
affect nonuniform work; no pointwise comparison is promised.
