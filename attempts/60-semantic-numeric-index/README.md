# A60 — A semantic numerical posterior index, before code

2026-10-17. New operation, not a reopening of A59's simple interval-core claim.
Written BEFORE a normalizer/index prototype, model readout or resource run.

1. **Real operation.** A typed numerical prediction consumer needs a median,
   credible quantiles or interval probabilities of a numerical field. Input
   is a finite weighted source for ONE frozen dLLM mean-field head, original
   token bytes/weights, fixed slots and a declared finite positive interval.
   Output is statistics of the induced distribution over exact decimal VALUES,
   aggregating every accepted spelling/token alias. Numerical LLM prediction
   and quantile consumers already exist; this is not a new application idea.
   Actual dLLM integration/usefulness is still unvalidated. The target is not
   the final distribution of an arbitrary iterative decoder.
2. **Candidate difference.** Compile a length-bounded, unambiguous numerical
   normalizer, then compose/project it with the weighted source to obtain a
   semantic value-key automaton. Boolean numeral recognition in A59 is not
   this index. Weighted transducers, projection, prefix sums and inverse-CDF
   selection are CLASSICAL. The specific normalizer/state bound and a useful
   implementation are candidates, not confirmed original discoveries. A
   generic complete WFST/prefix-cached implementation may match the benefit.
3. **Why choose it.** Potential exact numerical CDF/quantiles without sampling
   error or explicit enumeration of exponentially many values/spellings.
   Repeated fresh comparison-DP queries can repeat a precision-length factor;
   this is NOT a lower bound on all complete methods. Mandatory controls are
   cached complete register/digit DP, lazy semantic-prefix projection, generic
   filtered WFST composition and enumeration on small support. Monte Carlo,
   word MAP and fitted quantile probes are useful baselines, not adequate sole
   comparators. No measured win is currently available.
4. **Proof first.** work/theory-v1.md gives the normalization relation, linear
   fixed-band state bound, alias-mass identity, exact prefix quantile procedure,
   bit costs and a restricted sequential-transducer separation. The latter is
   a standard delayed-output argument, not a bound on every numeric algorithm.
   Median Bayes optimality is classical and subjective to the declared belief.
5. **First check.** Only small independent exact source/normalizer/index oracles
   after this note: unique normalization path, aliases/fixed slots, exact CDF
   and quantile boundary conventions against rational enumeration. No timing,
   training or native head campaign before equally competent complete controls
   and a separately frozen real-input/resource protocol. An illustrative
   alias-risk calculation is not a decoder/model benchmark.
6. **Complete costs.** Count source construction from original BPE IDs, bytes
   and finite weights; empty labels/EOT/PAD conventions; normalizer composition,
   epsilon handling, range conditioning, suffix masses, query work, bit lengths,
   memory and model forwards. Bounds are fixed metadata in the linear theorem.
   A large source/product graph can make this worse than a few direct queries.
   Exact mathematical values do not imply calibrated beliefs, binary64 consumer
   compatibility or a bitwise native RNG law. No new sampler law is claimed.
7. **Fatal objections.** The proposal may be only classical WFST composition
   and lexicographic unranking. A complete cached parser can obtain identical
   state reuse. Deterministic single-pass lower bounds omit legitimate string
   registers/multipass algorithms. A real user may only need a small number of
   cheap CDF queries. If a compact classical encoding matches the useful gain,
   recognize it and do not promote the method as own generic theory.
8. **Article obligations.** Specific antecedents and a substantive own
   consequence; independent normalizer/epsilon correctness; real useful
   dLLM numerical statistics with all original IDs/fixed context; full costs
   and complete controls. No trained model, numerical accuracy improvement,
   statistical calibration, human review, publication/admission guarantee or
   achieved positive goal is asserted.

Initial scope is an exact-decimal field in a fixed positive finite band. Bands
including zero permit unbounded negative decimal orders even with bounded
text length; they do not inherit the simple finite-order construction. Signs,
general recursive JSON extraction and whole-trajectory distributions require
separate arguments. Do not silently substitute canonical-only spellings.
