# V2: integer matching alternative, before prototype

This refinement preserves v1. The eight README questions remain binding.
Change the CONDITIONAL law: an even B-source pool is paired by a uniformly
random perfect matching having the MINIMUM number of equal-class pairs.
Retain the first literal source and return its matching partner. Conditional
raw-source marginals are uniform by matching symmetry. All empirical class
atom diagonals reach the same Frechet minimum; classes and matching are OLD
principles, not discoveries. Unknown-label source-budget frontier remains
restricted to the opacity model already stated, not transparent masks.

Potential benefit versus v1: integer completion counts enable exact choice
without an irrational calibration solve. Before implementing a real sampler,
check conditional and UNCONDITIONAL arbitrary-score covariance; a failed
matrix case blocks universal safety. No claim either has been proved. An odd
budget may use the preceding even pool (their atom frontiers coincide), but
will not be silently described as conditionally optimal on the larger pool.

The minimum same-class count is max(0,max r - B/2), by the classical complete
multipartite matching condition. Counting all optimal matchings may need many
count-vector states: this tiny oracle is not an efficient practical compiler.
Full cost, closest sampling/matching precedent and a useful dLLM/CFG role
remain prerequisites. No new model evaluations, timing campaign or change to
maintained code/article. Enumerated artificial populations are proof checks.

Search scope, chosen prospectively: even B<=12 for conditional partitions;
all original partitions M<=14 with at most6 classes and even2<=B<=M for the
averaged pool, with rational joint mass. Numerical eigenvalues ONLY locate a
counterexample; any positive result must be certified as a rational quadratic
form. Small exact matching enumeration independently checks the counting
recurrence. If no obstruction is found, the universal claim remains unproved.
