# A24 consumer V2 — exact numeric summaries and queried confidence

2026-10-13. Written BEFORE new implementation/timings. Refinement of A24,
not a fifty-first mathematical novelty claim. Historical source/results remain
unchanged; their timings do not belong to this producer.

1. **Real use.** A progressing JSON infilling decoder consumes a jointly valid
   original-token completion and the exact full-posterior confidence decisions
   needed to commit at most four positions. It does not consume an entire
   vocabulary-sized marginal matrix. Inputs are the original full binary64
   head, token bytes, fixed canvas, tolerance and threshold. New logits still
   require new paid evaluation at every changed canvas.
2. **Difference/significance.** This is systems work on the positive A24
   certificate, not a new quotient/inside-outside theorem. FactorDLM Proposition
   2 already gives class disintegration; A28 already has exact binary64 block
   statistics and recovery. Selective outside queries and early stopping are
   classical. Only useful complete-operation savings against equally optimized
   controls could justify this refinement. Publication significance is OPEN.
3. **Choice/comparators.** Replace Python per-token integer conversion and dense
   original marginals with the competent NumPy digit-sum control from A28 and
   queried original-ID marginals. Give the SAME boundary and queries to closed,
   handoff, grammar-hit, suffix-hit and full exact stack. In addition compare
   the same method with full sparse outside, which need not lift all V tokens.
   The old dense boundary is only an ablation, never the decisive opponent.
4. **Written guarantee.** See consumer-v2-proof.md. Common integer row scaling
   cancels. Global lexical classes preserve each original byte event. Inside
   gives the same mass, block recovery the same J_d law, and a prefix outside
   cursor gives the same numerator for a queried original ID. Stopping after
   the fourth CERTIFIED acceptance preserves the existing commit map. This
   proves equivalence/cost scope, not a new algorithmic principle or speed.
5. **Honest evaluation.** First use ALL 15 old independent frames, explicitly
   development now that they have been inspected; no fresh independence is
   claimed. Three rotated repeats, identical head/seed per paired comparison,
   all failures/zeros retained. Charge read/weights/preparation/sample/query,
   archived forward/softmax and static setup separately. Frozen protocol is
   consumer-v2-protocol.json. No new neural campaign before this gate.
6. **Complete cost.** The dense numeric head is still present. All input scans,
   integer digit reductions, block maps, scales, counters, depth trials, exact
   fallback, selected-block retrieval, confidence refinement, recognition and
   output count. NumPy's vectorized boundary is independently checked against
   Fraction, and is available to every parser. Report first operation/session
   cold and warm separately. No claim of neural-head memory reduction.
7. **Strong objection.** This may only repair an inefficient reference API.
   A full sparse outside competitor may win. Forward/parser costs may dominate.
   Compact exact controls retain their existing role and are required before
   a broad decoder-speed claim. Timed/censored successes need not have the
   unlimited kernel law; resource refusals are not exact target draws.
8. **Article requirements.** Need positive full-cost gate against stronger
   matched controls, complete iterative application, a justified consumer and
   credible novelty assessment of A24 itself. No academic acceptance, semantic
   improvement, trained dJev, EPIC superiority or new mathematical priority is
   guaranteed. A negative component screen does not fulfill the user's goal;
   retain it and investigate a materially different bottleneck.
