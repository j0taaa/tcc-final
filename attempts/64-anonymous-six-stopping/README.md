# A64 — Universal early stopping for the classical six-pool matching law

2026-10-17. Eight criteria BEFORE implementation or solver observation.
A63's finite count family, all failures and the closed A44/A42 consumers
remain unchanged. This is a distinct arbitrary-alphabet source-work question,
not another cap in the A63 family or a new matching/covariance principle.

1. **Use.** An opaque iid original-payload source and any fixed canonical key,
   with arbitrarily many possible keys. Produce the same raw ordered pair as
   the classical minimum-repeat six-pool matching, retaining the literal first.
   This removes A63's intrinsic three-key restriction for structured decoder
   outputs or simulator samples. A specific useful real full-cost consumer is
   STILL OPEN; no arbitrary two-output or three-bin application is imposed.
2. **Candidate difference.** A universal rule that stops after four draws on
   all-distinct inputs, with hard cap six and the same population pair law for
   EVERY source. The proposed consequence is sharp distinct-input source work
   and a25% diffuse-limit saving over EVERY algorithm preserving the matching
   conditional kernel on each full tape. Matching, restricted-growth patterns,
   Bernstein uniqueness, decision-tree flows and LP are classical. Sufficient
   own priority/significance remain open. No25% claim against all samplers.
3. **Choice.** The written contract gives a four-query lower bound and a16/3
   lower bound for the stronger tape-preserving control class. If attainable,
   the consequence is independent of alphabet size and not one more numeric
   cap constant. Different kernels, known-mass/seed/rank/RSS/CV/iid controls
   remain legitimate in a real final task. No wall-time advantage presumed.
4. **Proof first.** Work/contract-v1.md fixes the known target, proves the
   lower/control bounds, defines a finite anonymous flow certificate and gives
   the raw-payload lift and diffuse consequence BEFORE the LP. Existence of a
   four-draw distinct-input achiever is a CONJECTURE until certified.
5. **Minimal falsification.** One fixed six-pool matching target, no parameter
   selection. Constrain continuation after0123 to zero, minimize U3 work as a
   secondary comparison to the frozen386/81 bound. Exact rational feasibility,
   dual and independent named-tape verification required; preserve failure.
   No neural/data/timing campaign is triggered by a passing certificate.
6. **Full costs.** Charge all original calls including FAIL, classification,
   coordinator/RNG/table construction, rational bit work and consumption.
   Fixed cap supplies finite Wald for iid source work; preparation and output
   evaluation do not disappear. A population law equals the reference; native
   literal pairs and RNG tapes need not. No memory/latency theorem inferred.
7. **Objections.** The existing common-part construction is already optimal
   under its stricter per-tape contract. A64 exploits an iid-averaged contract;
   this distinction must stay explicit. Diffuse keys also give little absolute
   collision benefit, and iid2 is sufficient if non-atomic P is KNOWN. The
   application must justify universal exactness rather than hide information.
   The proposed primal may not exist or may require a U3 cost tradeoff.
8. **Article.** Need a surviving theorem, closest-source audit and a real useful
   operation against equally informed controls. This small proof prototype is
   justified only by the new dimension-independent comparative consequence.
   A correct sampler, source-call percentage or more code does not fulfill the
   user's goal. Preserve independent sources/evidence, no publication claim.
