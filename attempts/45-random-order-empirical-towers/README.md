# A45 — Random-order empirical towers: falsification first

2026-10-12. Written BEFORE this direction's prototype or observations. A44's
complete negative full-gradient diagnostic stays closed. No model campaign,
production change, article claim or publication novelty is authorized here.

1. **Use:** two expensive original loss/gradient or decoder continuations of
   a dLLM/CFG operation, selected using B cheap original draws and a fixed
   finite proxy. Original marginals, payloads and the literal first draw stay
   unchanged. A useful cheap proxy/source boundary is NOT established.
2. **Difference:** half-shifted towers, random ordering, empirical transports,
   reservoirs and atom bounds are OLD. The ONLY conjectural difference is
   unconditional all-target covariance safety of the particular random-label-
   order finite-pool law for arbitrary label count and budget. Three labels
   reduce to A44; six-budget minimum matching in A42 is a different kernel.
   If this is false or a direct known consequence, close this direction.
3. **Choice:** a possible linear-count/ticket implementation instead of
   enumerating pool matchings, while preserving every original marginal and
   (conjecturally) never increasing any projected pair variance versus iid2.
   Minimum-matching/pivotal, RSS, exact masses/inverses, CV and iid evaluation
   remain competent controls. No dominance over those methods is asserted.
4. **Without code:** prove/refute the UNCONDITIONAL matrix step below first.
   Conditional negative covariance under empirical masses alone is inadequate:
   the pilot mean fluctuates. Generic atom-optimal/balanced minimax arguments
   already exist in42/44 and are not a new claim of45.
5. **Validation:** the fixed protocol in work/contract-v1.md uses independent
   integer ticket enumeration, numerical adversarial screening and an EXACT
   rational certificate for any obstruction. Small constructed cases are
   mathematical falsification, never favorable benchmarks or model evidence.
6. **Cost:** B original draws, O(B+L) counters/reservoirs/tickets or interval
   bookkeeping, uniform permutation RNG and two expensive original target
   evaluations. Helper cost, fitting, bit arithmetic and source availability
   count. Enumeration of ALL permutations is only an oracle, not a fast sampler.
7. **Objection:** known systematic-resampling variance failures may persist
   after random label order; even a safe theorem may be known or useless for
   neural gradients. A44's weak three-class proxy is NOT revived or relabeled.
8. **Publication:** no implementation beyond a minimal independent refutation
   oracle until safety and an actual primary-source distinction survive.
   No acceptance, priority, practical gain or EPIC superiority is established.
