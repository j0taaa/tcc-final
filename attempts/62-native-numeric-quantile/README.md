# A62 — Certified numerical readout of a public autoregressive regression model

2026-10-17. Eight criteria BEFORE a quantile implementation, source-audit
producer, model weight download or neural execution. Read-only public source
inspection has already occurred and is recorded separately. This is a different
consumer from A60's frozen PRODUCT source and A61's declined training loss.

1. **Real operation.** Replace repeated-sample median estimation in a deployed
   code-to-metric regression model with a numerical quantile bracket, optionally
   refined to one value. RLM for Code documents sample-median readout; the public
   checkpoint provides an available frozen autoregressive consumer. Its output
   codec is a regular typed numerical language, hence a simple GLC case. It is
   NOT a dLLM; changing the TCC scope requires a useful result, not pretending
   the AR decoder is a one-head product law or inheriting diffusion evidence.
2. **Candidate distinction.** Investigate certified readout under the ORIGINAL
   scientific codec, including leading-zero mantissas, signed exponent0 aliases
   and the actual float conversion. Generic prefix probabilities, quantile
   inversion, branch-and-bound and endpoint enclosures are CLASSICAL. The
   possible contribution is a useful complete numeric operator/binding, not
   invention of those principles. Specific priority and substantial usefulness
   remain OPEN; a conventional encoding with the same benefit must be credited.
3. **Why choose it.** Potential deterministic control of error relative to the
   frozen model's population median, with less complete decoder work than a
   sufficiently accurate sample estimator. No speed/accuracy win is assumed.
   Compare cached/batched native sampling, stochastic CDF confidence controls,
   exhaustive prefix/CDF and equally optimized classical endpoint search.
   Canonical-only inverse CDF is mandatory when changing the prediction law is
   allowed; do not exclude it by calling the original law universally required.
4. **Proof first.** Write frontier-mass/range enclosures, monotone refinement,
   quantile and absolute-risk bounds, native rounding scope, full query/memory/
   bit costs and an oracle obstruction to universal cheap exact readout.
   A polynomial product-source algorithm cannot be transplanted to arbitrary
   AR probabilities. This theorem must be written before any query solver.
5. **First validation only.** Freeze a minimal SOURCE/CODEC audit before running
   it: pinned source hashes/configuration, AST inspection without importing or
   executing vendor modules, and independently evaluated literal float cases
   versus exact rational meanings. No weights, data rows, numerical predictions,
   labels or neural timings. This audit checks a contract, not a scientific win.
   Any later prototype/resource pilot needs a separate prospective protocol.
6. **Complete costs.** All methods share and pay encoder/preparation, cache setup,
   decoder forwards and prefix work, probability conversion/certification,
   parsing, scheduling, memory and output. Count rows and work, not only batched
   API calls. Native source probabilities depend on FULL token histories;
   different spellings of the same value must not share decoder state. A
   normalized exact law of stored conditional weights is not automatically
   the finite-RNG law of torch.multinomial. Record temperature/top-p/processor
   order before any execution; a changed support is a changed law.
7. **Objections.** Cached64 samples may be cheap after encoder work; exact native
   readout may need exponentially many histories in the worst case. A canonical
   codec makes ordinary ordered inverse CDF easy. Better direct heads and
   RELISH are practical alternatives if retraining is permitted; they are not
   the same frozen distribution and their label/training costs must be explicit.
   A certificate of model-median error is neither semantic accuracy nor model
   calibration. A classical endpoint search may already exhaust the novelty.
8. **Article obligations.** Own useful difference/priority, native correctness,
   complete competitive costs and relevant independent application are missing.
   First inspect the actual checkpoint codec, rather than assuming the paper's
   exponent size or exact-real semantics. No head/update/timing or achieved
   positive scientific goal is asserted. If the operator merely reproduces a
   known complete method without useful consequence, preserve it and decline
   expansion instead of adding features to manufacture novelty.
