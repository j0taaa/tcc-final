# Canonical token-aligned MWPC examples

These fixtures use the two-word language `{x y, z w}` (or its single-branch
restriction) and token IDs `x=10`, `y=20`, `z=30`, `w=40`.

1. **All compatible:** proposals `x@0:2` and `y@1:3` have witness `x y` and
   objective `5`.
2. **Jointly incompatible:** `x@0:4` and `w@1:5` are each extendable to a
   valid word, but no word contains both. The optimum is `z w` with objective
   `5`; the `x` proposal is not selected.
3. **Greedy confidence failure:** the highest-confidence proposal is
   `z@0:0.99`. Taking it forces unproposed `w`, scoring `0.99`. Exact MWPC
   instead takes compatible `x@0:0.80` and `y@1:0.79`, scoring `1.59`.
4. **Several optima:** equal proposals on `x@0` and `z@0` make both words
   optimal at objective `2`. Tests validate the score and certificate without
   requiring a particular optimum witness.
5. **Infeasible fixed canvas:** fixed tokens `x w` cross the two branches and
   are not generated by the grammar, so the status is
   `INFEASIBLE_ON_SUPPORT` with no objective.
6. **Duplicate proposals:** distinct IDs proposing the same `x@0` choice with
   weights `2` and `3` are both selected, along with `y@1:1`, for objective
   `6`.

All optimum claims are over the explicit four-token fixture support, not the
full model vocabulary.
