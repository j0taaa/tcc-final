The Python package contains independently readable reference solvers, proposal/support/lattice construction, orchestration, validation, the LLaDA adapter, and experiment code. The independent Rust 2021 crate \texttt{mwpc\_parser} implements the production max-plus CFG-on-acyclic-DAG dynamic program and backtracking; \texttt{mwpc\_parser\_py} is a thin PyO3 boundary. The integration exposes mutually exclusive \texttt{serial}, \texttt{epic}, and \texttt{exact} strategies and does not modify the baseline submodule.
