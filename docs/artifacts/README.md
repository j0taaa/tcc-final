# Research artifact storage and rebuild policy

Research outputs have three explicit layers:

```text
results/raw/<experiment>/<run-id>/
results/processed/<experiment>/<run-id>/
paper/generated/<artifact-id>/
```

Raw directories contain immutable JSONL measurements, resolved configs, and
replayable failure fixtures. Writers use create-only files and reject a raw
and processed directory that is equal or nested. Processed directories contain
deletable summaries, CSV, and plot-ready inputs. `paper/generated/` contains
small, tracked SVG and LaTeX derivatives that are generated by scripts and
must not be edited manually.

`scripts/exact_commit/build_publication_artifacts.py` is the publication
boundary. Its TOML config pins each raw JSONL SHA-256. It verifies that hash,
parses every finite JSON object, produces deterministic CSV, SVG, LaTeX, and a
provenance manifest, and checks that the raw file did not change during the
build. Create mode never overwrites outputs. `--verify-existing` recomputes
the expected bytes in memory and rejects hand edits.

## Versioned and external storage

Small raw inputs needed to reproduce tracked paper artifacts may be committed
under `docs/artifacts/raw/` with their producing commit and checksum in the
build manifest. Small processed and paper derivatives are committed under
`docs/artifacts/processed/` and `paper/generated/`.

Large raw runs remain ignored under `results/raw/` and must be published as an
immutable archive before their numbers are used in the paper. The archive
record must contain its stable download URI or DOI, byte size, SHA-256, git
commit, resolved-config hash, and the repository-relative regeneration
command. Model weights, caches, credentials, and private datasets are never
part of that archive. No external large-run archive is claimed by T1201; until
one is recorded, those local runs are reproducible diagnostics rather than
publication evidence.

Deleting processed and generated-paper outputs is always safe. Rebuilding from
the pinned raw input must reproduce the exact hashes recorded in
`artifact-manifest.json`; otherwise publication is blocked.
