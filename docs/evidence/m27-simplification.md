# M27 simplification audit

Scope: shared artifact plumbing and the budgeted compiler/orchestrator. No
baseline, independent weighted parser, brute-force oracle, scientific archive,
license or model adapter was deleted. The new certificates and formal proof
sources add necessary code; this work does not claim a net repository-size drop.

## Changes with concrete dependency evidence

| Removed duplication/work | Evidence | Preservation gate |
| --- | --- | --- |
| 27 helper bodies across `experiments/artifacts.py`, `statistical_artifacts.py`, `final_artifacts.py` | AST equality, including signature/body, before moving to 11 functions in `_artifact_io.py`; differing validators remain local | Artifact/statistical/final regression tests, unchanged raw hashes and byte-for-byte generated output checks |
| Budgeted use of ordinary epsilon normalization | The old wrapper built `build_eos_lattice` but consumed its original graph only; direct resource construction needs no unbudgeted saturation | Regression forbids calling that normalizer; original token/subset oracle agrees with private and compact layouts |
| Separate repeated resource-certificate check before the original-input check | Full original-input checker already calls the same independent resource checker | Forged witness/input/potential regressions continue rejecting; independent proof gate remains mandatory |
| Repeated fixed-canvas check in progress update | Mandatory original-input batch checker already verifies every fixed slot | Fixed-position and foreign-input update regressions pass |
| Old CLI-only fraction serializer | Portable proof codec uses `fraction_data`; removed name had no remaining callers | V2 JSON round trip and historical M26 graph-only verification |
| Second input-fingerprint/input codec | Wrapper reuses `budget_input_fingerprint` and strict saved `SelectionInput` codec | Foreign-input binding and altered emission/support/proposal tests |

The three artifact modules have 197 fewer lines combined; the shared helper
module has 98 lines, a net reduction of 99 lines for that consolidation. The
budgeted wrapper has 84 fewer lines, with graph construction/certificate
checking now in explicit reusable modules. Moving code is not counted as deleting
functionality.

Initial inventory: 145 Python source/script files and 45,386 lines. A later AST
reference scan covers 300 source/script/test files and 581 private top-level
functions, excluding their own recursive references: none lacks another
syntactic reference. This is a conservative inventory, not proof that dynamic
Python has no dead code. Deleting historical scripts just because their names
are unfamiliar would break experimental reproduction. Large ignored Rust build
caches are generated files, not committed scientific source.
