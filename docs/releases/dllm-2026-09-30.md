# Local delivery: live dLLM study, 2026-09-30

The local directory `dist/dllm-2026-09-30/` contains `source.bundle`,
`paper.pdf`, `manifest.json` and `SHA256SUMS`. It preserves the earlier bundles,
PDFs and tags. No remote publication is performed.

The parent bundle contains the main branch history and existing release tags,
current code/tests, frozen configs,
checksummed M24/M25 output, all recorded query attempts and generated article
sources. Model weights, caches, private data and credentials are excluded.
The manuscript PDF is also supplied separately from Git.

From the delivery directory, check `sha256sum -c SHA256SUMS`, then:

```bash
git clone ./source.bundle tcc-final
cd tcc-final
git submodule update --init --recursive
make bootstrap
make bootstrap-rust-parser
PYTHONDONTWRITEBYTECODE=1 make check
make query-demo-check
make article-results-check
make paper
```

EPIC is a separate read-only submodule pinned to `5b1b310`; its repository is
not embedded in the parent bundle. First setup requires dependencies/submodule
access. Once installed, archive verification, table regeneration and query
replay do not need network, model or GPU. The clean artifact rehearsal also
regenerates the main M24/M25 products from a non-editable wheel installation.
[Complete instructions](../../REPRODUCING.md).

tests with eight existing skips. A clean clone at source `5238e7e` rebuilt all
