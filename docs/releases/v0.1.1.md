# Licensed submission release v0.1.1

`v0.1.1` is the immutable private-repository institutional-submission and
reproducibility release for the exact MWPC implementation, the SBC article
source, and the evidence used by that article. It supersedes `v0.1.0` as the
recommended checkout without rewriting that historical release or any
experiment provenance. The Python package version in `pyproject.toml` is also
`0.1.1`.

The author's original parent-repository software and research artifacts are
licensed under the MIT License in `LICENSE`; `LICENSES.md` defines the exact
scope. The manuscript's publication rights remain separate. The pinned EPIC
submodule and every other third-party file remain under their own notices.

## Release assets and archived evidence

The GitHub release contains:

- `mwpc-exact-v0.1.1-paper.pdf`, rebuilt from the tagged LaTeX source;
- `mwpc-exact-v0.1.1-evidence.tar.gz`, an evidence-only archive; and
- `SHA256SUMS`, covering both assets.

The evidence archive contains the parent license and attribution file, tracked
analysis and experiment configs, small raw JSONL inputs, processed JSON/CSV
outputs, evidence summaries, paper source plus generated tables/figures, and
reproduction instructions. Build it from the tag with:

```bash
mkdir -p dist
git archive --format=tar.gz \
  --prefix=mwpc-exact-v0.1.1-evidence/ \
  --output=dist/mwpc-exact-v0.1.1-evidence.tar.gz \
  v0.1.1 \
  LICENSE LICENSES.md REPRODUCING.md UPSTREAM.md configs docs/artifacts \
  docs/evidence docs/releases/v0.1.1.md paper
```

This is not a standalone source checkout: it deliberately does not duplicate
the read-only EPIC submodule. Use the recursive tagged clone in
`REPRODUCING.md` to run code. GitHub's tag source archives likewise retain the
gitlink but not the submodule contents.

## Release gates

The release gate covers the complete Python suite; Rust formatting, tests, and
Clippy for both production crates; a rebuilt PyO3 binding; release-wheel
installation outside the checkout; byte verification of T1203 and M13
derivatives; both clean CPU rehearsal levels; and a rebuilt, visually inspected
16-page PDF. The release-wheel rehearsal also verifies the MIT expression and
root license file in the wheel.

## Boundaries and external dependencies

- Every optimizer claim remains per-step `exact_on_support`; top-K support is
  not full-vocabulary exactness, and `TIMEOUT` is not support infeasibility.
- Q2 real snapshots reduce to singleton represented supports, Q4 uses generated
  compound graph-size settings, and Q5 covers two literal structured tasks on
  one machine. These bounds remain in the article.
- The pinned EPIC repository must remain available at commit
  `5b1b31098f34ed3691d2a9f4aae14fdf5839d072` for a recursive clone.
- Optional live Q5 reruns require the external, revision-pinned
  `GSAI-ML/LLaDA-8B-Instruct` checkpoint, a compatible NVIDIA/CUDA environment,
  and local model cache. Weights, caches, and credentials are not archived or
  licensed by this repository.
- Bootstrap may require the configured Python and Rust package registries; the
  paper build additionally requires a compatible TeX distribution.
- The MIT parent license does not replace EPIC's license, third-party notices,
  or the manuscript's separate publication terms.
- Author, advisor, campus/address, and email fields are complete. Advisor review
  remains a separate unchecked institutional workflow item.
