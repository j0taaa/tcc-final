# Local delivery: certified repair, 2026-09-28

This supersedes the M20 snapshot as the current source delivery without replacing
any historical tag, patch, raw result or PDF. No remote publication is performed.

The local directory `dist/repair-2026-09-28/` contains:

- `source.bundle`: complete parent Git history and current source, tests, frozen
  configs, checked-in small raw archives and generated paper sources;
- `paper.pdf`: the compiled 16-page manuscript;
- `manifest.json`: source commit, measurement commit and artifact hashes;
- `SHA256SUMS`: verification of these delivery files.

From this directory, run `sha256sum -c SHA256SUMS`, then:

```bash
git clone ./source.bundle tcc-final
cd tcc-final
git submodule update --init --recursive
make bootstrap
make bootstrap-rust-parser
make check
make article-results-check
make paper
```

The EPIC submodule has its own upstream repository; it is not embedded in the
parent Git bundle. Its immutable commit and license are in `UPSTREAM.md` and
`THIRD_PARTY_LICENSES.md`. A first setup needs dependency/submodule access; raw
artifact verification then needs no model, tokenizer download or GPU.

Measurements were produced by clean commit `47b93c4` with frozen M21 configs.
The delivered source additionally improves offline archive validation and paper
reproduction; those changes do not overwrite measurements. Exactness is on the
represented finite support. The study uses controlled corruptions and a real
tokenizer, not real generated errors, model retries or a full-vocabulary guarantee.
It shows a restricted recovery benefit, retains failed classes and the historical
negative end-to-end generation result. See `docs/research/m21-findings.md`.
