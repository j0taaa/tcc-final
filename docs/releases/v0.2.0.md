# Local submission release v0.2.0

This is the local reviewed submission, including the exact-score hardening,
sparse-chart deadline fix, matched schedules, nonliteral experiments, corrected
proof exposition and revised article. The Python package version is 0.2.0.
It supersedes v0.1.1 as the recommended delivered source. Historical tags and
measurements remain unchanged. This release has not been pushed or published.

The delivered assets in dist/ are:

- mwpc-exact-v0.2.0.bundle: source history and the local tag;
- mwpc-exact-v0.2.0-paper.pdf: the revised article;
- mwpc-exact-v0.2.0-evidence.tar.gz: evidence-only archive;
- SHA256SUMS: checksums for those files.

The evidence-only archive is not a standalone source checkout. It contains
LICENSE, LICENSES.md, REPRODUCING.md, UPSTREAM.md, configs, docs/artifacts,
docs/evidence, release notes and paper source/generated results. Clone the
bundle, check out v0.2.0, and initialize the pinned EPIC submodule as described
in REPRODUCING.md. The source bundle retains the parent Git history; a submodule
requires its separately pinned upstream repository.

## Evidence and limits

The new bundle is docs/artifacts/raw/m17_review_v1. Its six subdirectories
preserve the synthetic study, both pilots (including observation failures),
disjoint confirmation, saved-state replay and recursive scaling. Each has a
SHA-256 manifest and compressed raw JSONL. Measurement rows retain their
producing commits, configuration hashes, model/support specifications and
statuses. Regenerate the manuscript additions with:

    .venv/bin/python scripts/exact_commit/build_review_results.py
    .venv/bin/python scripts/exact_commit/build_review_results.py --check

The experiments support per-step exact_on_support, not full-vocabulary
exactness. TIMEOUT is not support infeasibility. Synthetic recursive cases
exhibit some greedy gaps, while genuine model-state replay found none.
Matched-budget nonliteral generation did not establish an end-to-end advantage;
incomplete and functionally unsuccessful outputs remain in all denominators.
Historical Q5 runtime ratios used unequal proposal budgets and cannot isolate
the effect of selection. Full configurations and repeated measures are retained.

The optional live studies use GSAI-ML/LLaDA-8B-Instruct at its pinned revision.
Weights, caches, and credentials are not archived. The MIT parent license does
not replace EPIC's license or the manuscript's separate publication rights.
Author/advisor approval for institutional submission is a separate human step.
