# Entrega matemática, 30/09/2026

Esta revisão substitui o foco empírico do TCC por **compromisso paralelo ótimo
sob orçamento físico, com prova verificável de optimalidade**. A contribuição
segue dos teoremas e independe de vitórias em benchmarks. As entregas M25 e
anteriores permanecem separadas e todos os resultados negativos são preservados.

O núcleo está em [definições e provas completas](../research/m26-mathematical-core.md)
e na seção matemática do artigo. O problema escolhe uma conclusão válida e até B
posições livres conjuntamente. Para as mesmas propostas, suporte, slots fixos
e orçamento, o algoritmo alcança peso pelo menos igual ao de qualquer lote
viável. Famílias infinitas numa única linguagem regular mostram que pré-seleção
por confiança e pós-filtragem do ótimo sem orçamento podem ter razão de
aproximação que tende a zero. Isso é separação matemática, não taxa de acurácia.

O protótipo racional inclui CFG/DAG com epsilon, bytes, EOS/PAD, custo por posição,
duplicatas e testemunhas originais. O checker independente verifica potenciais
superiores e uma testemunha que atinge o limite, comprovando optimalidade sem
confiar na decisão do solver. A fronteira também fornece o orçamento mínimo
para uma recompensa-alvo. O limite ótimo de rodadas exige atualizações
irreversíveis e suporte que retenha a testemunha.

Reprodução da contribuição, sem modelo, GPU ou rede após instalar o pacote:

```bash
python scripts/exact_commit/budget_math_example.py --output /tmp/budget-proof.json
python scripts/exact_commit/budget_math_example.py --verify /tmp/budget-proof.json
python -m pytest -q tests/exact_commit/test_budgeted_math.py
```

Use um caminho de saída novo. O JSON contém a CFG, o grafo de recursos original,
os potenciais racionais e a fronteira completa. O modo de verificação não importa
o otimizador. O exemplo não é um benchmark. A API pública está em
`mwpc_exact.budgeted_commit`; `serial | epic | exact` permanecem disponíveis.
Esta nova dimensão está no solver racional de referência, sem alegar integração
Rust rápida ou novos resultados de geração.

A entrega local fica em `dist/math-2026-09-30/`, com `source.bundle`, `paper.pdf`,
`budget-proof.json`, `manifest.json` e `SHA256SUMS`. O manifest identifica o commit
e os hashes; o bundle contém as provas, código, testes, artigo e a evidência
histórica. Pesos, caches, credenciais e dados privados não são incluídos.

```bash
sha256sum -c SHA256SUMS
git clone ./source.bundle tcc-final
cd tcc-final
git submodule update --init --recursive
make bootstrap
make bootstrap-rust-parser
make check
make release-wheel-smoke
make article-results-check
make paper
```

EPIC é submódulo separado, fixado em `5b1b310`; o setup inicial precisa de acesso
às dependências e ao upstream. O ambiente instalado verifica provas e arquivos
offline. [Guia completo](../../REPRODUCING.md) e
[evidência da revisão](../evidence/m26-mathematical-verification.json).

A contribuição é incremental: parsing ponderado, DP com recursos, inferência
exata e algoritmos certificadores são antecedentes reconhecidos. Não se afirma
prioridade mundial, melhor acurácia semântica, menor latência, optimalidade da
trajetória futura ou prova mecanizada em Lean/Coq. As provas são matemáticas
escritas; testes e checker verificam a implementação e as instâncias. A revisão
pelo orientador continua sendo uma etapa humana de submissão.
