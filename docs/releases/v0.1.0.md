# Reproducibility release v0.1.0

`v0.1.0` is the immutable private-repository release for the exact MWPC
implementation, the SBC article source, and the evidence used by that article.
The Python package version in `pyproject.toml` is also `0.1.0`. Experiment rows
retain their own producing commits; the release does not rewrite provenance.

## Release assets and archived evidence

The GitHub release contains:

- `mwpc-exact-v0.1.0-paper.pdf`, rebuilt from the tagged LaTeX source;
- `mwpc-exact-v0.1.0-evidence.tar.gz`, an evidence-only archive; and
- `SHA256SUMS`, covering both assets.

The evidence archive contains the tracked analysis and experiment configs,
small raw JSONL inputs, processed JSON/CSV outputs, evidence summaries, paper
source plus generated tables/figures, and reproduction instructions. Build it
from the tag with:

```bash
mkdir -p dist
git archive --format=tar.gz \
  --prefix=mwpc-exact-v0.1.0-evidence/ \
  --output=dist/mwpc-exact-v0.1.0-evidence.tar.gz \
  v0.1.0 \
  REPRODUCING.md UPSTREAM.md LICENSES.md configs docs/artifacts docs/evidence \
  docs/releases/v0.1.0.md paper
```

This is not a standalone source checkout: it deliberately does not duplicate
the read-only EPIC submodule. Use the recursive tagged clone in
`REPRODUCING.md` to run code. GitHub's tag source archives likewise retain the
gitlink but not the submodule contents.

## Release gates

The release gate covers the complete Python suite; Rust formatting, tests, and
Clippy for both production crates; a rebuilt PyO3 binding; release-wheel
installation outside the checkout; byte verification of T1203 and M13
derivatives; both clean CPU rehearsal levels; and a rebuilt, visually inspected
16-page PDF. Exact command results are recorded under T1304 in `TASKS.md` and
in the GitHub Actions run linked there.

## Boundaries and external dependencies

- Every optimizer claim remains per-step `exact_on_support`; top-K support is
  not full-vocabulary exactness, and `TIMEOUT` is not support infeasibility.
- Q2 real snapshots reduce to singleton represented supports, Q4 uses generated
  compound graph-size settings, and Q5 covers two literal structured tasks on
  one machine. These bounds remain in the article.
- The pinned EPIC repository must remain available at commit
  `5b1b31098f34ed3691d2a9f4aae14fdf5839d072` for a recursive clone.
- Optional live Q5 reruns require the external, revision-pinned
  `GSAI-ML/LLaDA-8B-Instruct` checkpoint, a compatible NVIDIA/CUDA environment,
  and local model cache. Weights, caches, and credentials are not archived.
- Bootstrap may require the configured Python and Rust package registries; the
  paper build additionally requires a compatible TeX distribution.
- The parent research-code license remains an author decision in `LICENSES.md`.
  This private release does not grant a public redistribution license or alter
  EPIC's own notices.
- The article source retains only three non-scientific identification fields
  that the author has not supplied: advisor, campus/address, and email. They
  must be completed before institutional submission; no implementation or
  measured-result field remains unresolved.
